Backup & export

        
Your records are stored only in this browser (). Clearing browser data deletes them. Export a JSON backup regularly and keep it in a secure, access-controlled location.

        

        

        
Import

        
JSON backup from this app, or CSV using templates/import-template.csv. Dates may be YYYY-MM-DD or DD/MM/YYYY. Entries with an existing id are updated, not duplicated.

        
        

      

      
Import yearly hospital registry (.xlsx)

        
Choose the registry Excel export (e.g. Year_2027.xlsx). The file is read inside this browser only. Cases with your name in a doctor column are added with patient name, NRIC, HRN, diagnosis, registry wording, role and anaesthesia. Domain and procedure are suggested automatically and flagged for checking. Cases already in the log book are skipped, so corrections you made are kept.
